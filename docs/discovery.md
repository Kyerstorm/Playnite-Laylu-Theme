## Survey gaps

1. No addon Ids, which every `PluginStatus` guard needs. Filled above for installed extensions only.
2. No extension versions or maintenance status. A control name hosted by an old theme may no longer exist.
3. No `PluginSettings` property paths (data that themes read without hosting a control).
4. The control list is a union across themes, so it mixes current and legacy names.
5. Pricing, statistics dashboards and random-pick are not covered at all.
6. Three extensions named in the brief do not appear under those names: GameDetailsView, Game Completion Status, Game Statistics.
7. It does not record which views each control was hosted in (details, grid item, grid side panel).

## Outstanding questions

- Players online now as a raw value for the stats strip (D-057): unverified. If only the extension's control exists, it is hosted in the strip with the extension's own look.
- Unread-notification count for the dot (D-065): only `Settings NotificationPanelVisible` was found in Default. Needs Playnite source.
- Switching view from the sidebar (D-062): `MainViewModel` commands are reachable from any view (Default uses `MainViewModel CloseGameSideBarCommand`), but the view-switch command's name is unverified.
- The grid's side panel has a native close button and Playnite's own show/hide state. "Always open" (D-027) means the theme removes the close button; whether a closed state can be overridden is unverified.
- Auto-hide top bar: feasible in a theme. Vesper Glass's `Views/TopPanel.xaml` does it with `IsMouseOver` triggers, a named hover zone and opacity plus vertical-translate storyboards. Still open: keeping the bar shown while the search box has keyboard focus, and whether a filter-active value is bindable for the marker.
- Ratings out of 10 (D-053): needs a way to show a tenth of Playnite's 0 to 100 score without code. Unverified; fallback is to show the score out of 100.
- Trailer autoplay and mute are Extra Metadata Loader's own settings, not something the theme controls.
